Date: 2026-09-29. **Implementation turn: source changed; no build, test, package, or game run was launched.** The [previous render-target batch](validation-p0-render-target-2026-09-29-01.md) passed 28 backend tests and a hidden dynamic-rendering clear/blit/present frame.

The backend compile list now includes the original shader interface layout, GLSL 330 rewriter, shaderc compiler, SPIR-V binary cache, program translator, native shader builder and library, frame globals, and shader trace methods. `Silk.NET.Shaderc` and its native package are declared at the original pinned `2.23.0` version. The atomic cache writer moved unchanged out of `PipelineCachePersistence` so both binary and later driver caches can share it when the pipeline cache joins the build.

The seven shader source files that used Vintage Story's `EnumShaderType` now alias that source identifier to the neutral `ShaderStageKind`. The mapping from the official enum is staged in `porting/game-adapter/GameShaderStage.cs`. Stage ordering, rewrite rules, shaderc options, reflection behavior, manifest schema, and native variant logic remain in their existing bodies. The fresh cache key uses `vulkanstory-spirv-`; native shader environment names are `VULKANSTORY_VK_NATIVE_SHADERS` and `VULKANSTORY_VK_SHADER_SOURCE`.

The existing GLSL corpus still uses shader ABI identifiers such as `OptimumFrameGlobals`, `OptimumUniforms`, and `OPTIMUM_SAMPLER_SLOT`. Those names are matched by its current source and reflection rules and do not load Optimum at runtime. Renaming them requires a coordinated shader-source and manifest change after the ported path is verified; no ABI rename was mixed into this boundary extraction.

`tools/VulkanStory.Shaders.Compiler` now exposes the retained `NativeShaderTool.Run` command line from this repository. Two focused tests carry the source expectations for indexed bindless sampling through rewriting and shaderc compilation, and for rejecting a damaged SPIR-V cache payload.
