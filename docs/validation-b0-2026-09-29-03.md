The file is present at `C:\Users\N1GHT\AppData\Roaming\Vintagestory\Lib\OpenTK.Mathematics.dll`. The next implementation turn should install an early, identity-checked resolver for the game's own `Lib` dependencies, then keep rollback from obscuring the original binding error.
